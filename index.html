⚡ Scaling Rules
New business → new BA + BenOS folder + Google Drive + MCP credentials
EA and SIL are unchanged.
New client → /client-onboard → AM skill + BenOS/Clients/[name]/ + Linear project
BA-Catalyzing is unchanged.
New skill → add to department catalog, reads BenOS context on load
Agent hierarchy is unchanged.
New platform → new MCP credential + new format skill
Everything else is unchanged.
New skill needed → COO intake → Skill Brief → Ben approves → Skill-Creator builds → COO adds to registry
Ben is approval gate. COO defines. SC builds. Never both.
New tool needed → COO intake → coverage check → cost/complexity score → Approve / Defer / Redirect / Reject
Default answer is NO. Ben confirms any approval.

COO defines — Skill-Creator builds — never both
