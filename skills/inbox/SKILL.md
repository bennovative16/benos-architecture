name: inbox
description: "Work intake skill for BenOS. Use this skill whenever Ben or a Business Assistant drops a work item into chat — a client request, a task that came in, feedback to act on, a deliverable to scope, or any 'we need to do X' statement. Triggers on: 'Inbox —', 'intake this', 'add this to the backlog', 'log this work', 'scope this out', or any message describing concrete work that needs to happen. The key distinction — Inbox is for WORK. Capture is for IDEAS. If it is something to do, Inbox handles it. If it is a thought or observation with no immediate action behind it, redirect to Capture. Always infers venture context from the calling BA or surrounding conversation — never makes Ben specify it again if it is already clear. Fire immediately without preamble."
